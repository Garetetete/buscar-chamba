# Práctica Wonderlic — Sezzle

Preparación para la parte cognitiva del test Wonderlic que pidió Sezzle (plazo: martes 13 de octubre de 2026).

## Cómo es el test

- La parte cognitiva dura **12 minutos**. Mide razonamiento rápido, no programación.
- El ritmo real es de **unos 15 segundos por pregunta**. Casi nadie termina todas.
- Si una pregunta te toma más de 20 segundos, **sáltala** y sigue. Las fáciles valen lo mismo que las difíciles.
- Puede haber secciones de **personalidad y motivación**. No tienen respuestas correctas: responde con honestidad y coherencia.
- Lee el folleto adjunto del correo de Sezzle: ahí dicen si se permite calculadora o papel.

## Tipos de preguntas

| Tipo | Ejemplo |
|---|---|
| Series de números o letras | 2, 4, 8, 16, ? |
| Matemática de la vida diaria | Descuentos, porcentajes, velocidades, proporciones, trabajo en equipo |
| Vocabulario | Sinónimos, antónimos, significado de una palabra |
| Analogías | "Book is to read as knife is to…" |
| Lógica | "All A are B; some B are C; are some A C?" — true, false o uncertain |
| Ordenar una frase | Palabras desordenadas que forman una oración: ¿es verdadera o falsa? |
| El que no pertenece | Cuál palabra o número no encaja |

## Cómo usar este cuestionario

1. Ponte un cronómetro: **5 minutos por ronda** (20 preguntas, el mismo ritmo del test real).
2. Escribe tus respuestas en un papel, sin calculadora.
3. Al terminar, abre las respuestas al final de cada ronda y cuenta tus aciertos.
4. Repasa las explicaciones de las que fallaste y anota qué tipo te cuesta más.

**Referencia:** 14 o más aciertos de 20 en 5 minutos es un buen ritmo para el test real.

## Trucos que ahorran tiempo

- **Series:** mira primero las diferencias entre números. Si no hay patrón, prueba multiplicaciones o cuadrados.
- **Porcentajes:** 10% es mover la coma; 5% es la mitad de eso; 25% es dividir entre 4.
- **Fracciones contra decimales:** memoriza 1/4 = 0,25, 1/3 ≈ 0,33, 3/8 = 0,375, 5/8 = 0,625, 2/3 ≈ 0,67.
- **Lógica:** si la conclusión "podría" ser cierta pero no es obligatoria, la respuesta es *uncertain*.
- **Frases desordenadas:** busca primero el verbo y el sujeto; el resto cae solo.
- **Trabajo en equipo:** suma lo que hace cada uno por hora y luego invierte.
